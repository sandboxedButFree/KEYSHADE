# KEYSHADE

KEYSHADE is a standalone password manager that allows user to store and view passwords after Authentication. It was built as a professional development project and will continue to be updated over time.

# User Guide

1. Clone the Repository
```
git@github.com:sandboxedButFree/KEYSHADE.git
```

2. Set up a Virtual Environment
```
python -m venv venv
```

3. Install Requirements
```
pip install -r requirements.txt
```

4. Run Program
```
python main.py
```
